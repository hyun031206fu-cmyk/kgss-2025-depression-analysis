## 📌 프로젝트 개요
* **연구 주제**: 16세 당시 가족구조와 성인기 현재 우울감(CES-D) 사이의 관계
* **자료 출처**: 한국종합사회조사 2025 (KGSS 2025, N = 1,156명 확정 표본)
* **핵심 변경 사항**: 기존 5개 가족구조 유형을 **3개 유형(친부모 가구, 한부모 가구, 부모 재구성·비동거 가구)**으로 재분류하고 전체 통계분석(t검정, OLS 4단계, 로지스틱, 세대별 상호작용, 가중치 회귀)을 재실행함.

## 💡 주요 분석 결과 요약
* **연구 가설 지지**: 16세 당시 친부모 비거주 가구 출신은 친부모 가구 출신에 비해 성인기 우울감이 유의하게 높음 ( = 1.031, p = .0016^{**}$).
* **3개 유형 비교**:
  * 한부모 가구 (N=98): 통제 전  = +0.99$ ( = .0086$) $\to$ 통제 후  = +0.65$ ( = 0.0799^{\dagger}$, 한계적 유의)
  * 부모 재구성·비동거 가구 (N=32): 통제 후에도  = +2.170$ ( = 0.0005^{***}$)로 매우 높은 우울 위험 유지
  * 두 집단 간 차이: 부모 재구성·비동거 가구가 한부모 가구보다 우울감이 $+1.52 유의하게 높음 ( = 2.15, p = 0.0315^{*}$).
